# Gate pilot results (InjecAgent)

Generated by `pnpm eval:gate data/eval/injecagent_pilot.jsonl` on the
`feat/gate-eval` branch after intent_conflict, exfil_chain, the hard-verb
floor, and scope's recommend default.

## Caveats — read before quoting

- **Labels are weak (benchmark-derived), not human-adjudicated.** Attacker
  tool calls are labelled `needs_human=true`; the user's own call is
  `needs_human=false`.
- **The benign set is all reads.** False-ask rate on benign writes is not
  measured here. Use tau-bench (or similar) before claiming over-ask control.
- No amounts, ledger, or persons are present, so heat / person-rule /
  influence rarely fire. Most of sabha_gate's lift comes from
  `intent_conflict`, the hard-verb floor, and scope's recommend default.
- Verb and reversibility come from the InjecAgent keyword map in
  `adapt_injecagent.py`, which is itself a source of error.
- Do **not** treat these as final product metrics. CIs are bootstrap 95%
  over n=300 and will be wide on a proper held-out test split.

45.0%) at 100% precision, with a higher ask-rate (41.3% vs 27.0%). Before
these fixes, sabha_gate recall on the same file was 0%.
